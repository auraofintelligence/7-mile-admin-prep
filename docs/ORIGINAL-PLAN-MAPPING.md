## Source corrections and interfaces

7-Mile is on a native title claim. Specific claim records, mapped boundaries and existing agreements remain inputs. C-Hours have no financial aspect. Maker-Space, Tip Loop and Capsule Surge remain distinct proposals; no shared location, ownership, clinical service or compute installation is inferred.

The Tip Loop governance page contains older financial issuance and redemption language. This is excluded from 7-Mile drafting. The Capsule Surge model has no nominated site. The Maker-Space location proposal discusses Dunwich / Goompi.

## Staging

Source reading and needs briefs proceed alongside entity decisions. Site preparation follows actual permissions. Layout and service options inform the chosen first stage. Procurement follows evidence and funding decisions. Only briefs relevant to that stage enter its release pack; later concept works are not blanket prerequisites for a small cultural activity.
