- household and studio needs
- supplier dimensions and evidence
- freight access
- foundations
- utility loads
- actual quotes

- [ ] 20 expandable 40-foot options at about 74 m2 each
- [ ] 20 expandable 20-foot options at about 37 m2 each

- [ ] use and occupancy for each type
- [ ] foundations and assembly
- [ ] ferry freight unloading and lifting
