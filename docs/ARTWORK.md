# Generated artwork

Generated using the built-in image generation tool for this website. All scene briefs specify a completely landlocked sandy bushland setting, with no sea, bay, lake, creek, beach or water horizon. Images are concept artwork, not site photographs or boundary evidence. No cultural authority or sacred designs are represented.

| Asset | Page use |
| --- | --- |
| overview.webp | Overview and business/operations document pages |
| tasks.webp | Task register |
| documents.webp | Document studio and entity documents |
| checklists.webp | Checklists and land/approvals documents |
| references.webp | References and governance documents |
| agencies.webp | Agencies and relationship documents |
| decisions.webp | Decisions and founding documents |
| sitemap.webp | Site tree |
| favicon.png / favicon.ico | All pages |

Scene prompts are preserved in `scripts/artwork-prompts.json`.
